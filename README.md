# 時間割（シラバス連携）

曜日×時限の表に授業を登録すると、タップでその授業のシラバスがすぐ見られるアプリです。

## 主な機能
- 時間割: 時限数・表示する曜日・各時限の時間を自由に設定できます。右上の「編集」で、コマに授業を登録します。
- シラバス: PDFで配られたシラバスの内容（学習内容・到達目標・評価方法・授業計画など）を、タップしたコマから見られます。
- 候補が複数あるコマ（他専攻の授業と同じ時間など）は、検索して選べます。シラバスに無い授業は「新規作成」で自分で入力できます。
- スケジュール: 自分で入力する予定・締切の一覧です。
- 年間予定表: 準備中です（データが届き次第、表示します）。
- メモ: 自由に書けるメモです。

## データについて
- `syllabus-data.js` は、学校配布の「2026年度後期シラバス」PDF（272件）の内容を、文字として抜き出したものです。**PDFファイル自体はこのリポジトリに含めていません。**
- ID・パスワードなど、個人を特定する情報は含めていません。
- 登録した時間割・スケジュール・メモは、この端末（ブラウザ）の中だけに保存されます。

## 公開範囲
検索エンジンには出ないようにしています（`noindex`）。URLを知っている人だけが開けます。クラスの一部の友達だけに、URLを渡して使う想定です。学校の授業内容が含まれるため、URLを広く転送しないでください。
